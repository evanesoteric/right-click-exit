## [1.0.0] - 2026-11-06

### Added
- Right-click closes any screen that Escape closes (dialogue, ATM, shops, pawn
  shop, storage, handover, casino tables, vehicle mods, customization, pause
  menu and more), using each screen's own close logic.
- Right-click never opens the pause menu during normal gameplay, and keeps its
  normal meaning for inventory slots, station tasks and management selectors.
- `Enabled`, `CloseTasks` and `VerboseLogging` preferences.
- Builds for the IL2CPP (main) and Mono (alternate) game branches.

Tested on Schedule I v0.4.7f12 with MelonLoader v0.7.3.
